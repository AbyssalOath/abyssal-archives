Only the public key. Signing happens on your own machine; see docs/VERIFYING.md.

External sharing (all off by default)

Public file lists get "Mirror (…)" and "Torrent (…)" links to copies hosted elsewhere (Archive.org, GitHub, other servers) that you approved. Visitors' browsers go to those sites directly; this server never proxies them. Off: mirrors stay stored but are not shown.

For torrents this site generates in the future: public (found via DHT and peer exchange) instead of private-flagged. Public mode exposes the seeder's IP (the VPN IP if the seeder profile is used). Never run a seeder outside the VPN container.

Planned: look files up by hash on known public hosts and suggest mirrors as "pending". Makes no network requests today.

Planned: exchange signed (hash, mirror URL) lists with other opted-in instances; everything received would start "pending". Makes no network requests today.

Member accounts

Anyone can ask for an account; every request waits for your approval under Users (there is no e-mail: applicants find out by signing in). Off: /register says requests are suspended and shows the contact address below. You can always create member accounts yourself.

New and changed member projects and releases, and releases they upload to, stay hidden until you publish them under Review. Off: members publish directly (you can still unpublish anything).

Defaults for every member; set higher limits for one member under Users (members can ask on their Limits page).

Site name, tagline, download base URL and the sharing toggles start out from .env (SITE_NAME, SITE_TAGLINE, DOWNLOAD_BASE_URL, EXTERNAL_MIRRORS_ENABLED, ...). Once you save a different value here, this page wins; saving the same value as .env hands control back to .env.
